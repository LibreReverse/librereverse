# Features

LibreReverse records screen history and meetings on your Mac. These are the main
surfaces to check when changing the app; use the [UI checklist](UI_CHECKLIST.md)
for detailed visual and interaction coverage.

## History

- Open from the menu or a configurable shortcut; optionally use the scroll gesture.
- Scrub captured moments, change time scale, jump by date and hour, or return to now.
- Identify applications, starred moments and meeting audio on a single timeline.
- Search captured text, filter by application or meetings, and browse starred moments.
- Select and copy recognized text, reopen recorded URLs, and save or share moments.
- Restore archived recordings on demand with progress and cancellation.

## Meetings and summaries

- Start recording manually or detect supported calls automatically.
- Capture system audio and optional microphone audio; transcribe locally.
- Browse meeting waveforms and synchronized transcripts; move or pin the reader.
- Edit meeting details and participants, copy or export transcripts, and delete meetings.
- Browse Daily Recap and meeting details; summarize or ask questions using an AI profile.
- Continue Ask with follow-up questions in a chat, inspect each answer’s sources, and track or cancel requests. Configure profiles and keys in Settings → AI.
- Associate meetings with selected calendars when Calendar access is granted.

## Settings

| Page | Controls |
| --- | --- |
| General | Launch at login, pause reminder, Dock visibility, permission setup |
| Screen | Excluded applications, background processes, private windows, OCR languages |
| Meetings | Detection and start policy, audio sources and device, transcription language, permissions, calendars |
| AI | Profiles, local or remote provider, model, API key, default routing and fallback |
| Storage | Drive or S3, connection fields and status, local retention, archive usage and backup time, deletion |
| Shortcuts | History, Ask, Recap, meeting recording and text-selection shortcuts; clear/restore and scroll invocation |

Setup explains required permissions and can restart the app after access changes.
The menu shows capture/meeting state and provides Settings, backups, updates and Quit.
See [archive storage](ARCHIVE_STORAGE.md) for connection and retention behavior,
and [UI behavior](UI.md) for interaction requirements.
